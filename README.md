# Cheerio Setup Copilot: clickable prototype

Prototype for Cheerio's Product Intern Assignment A: make customer support scale for non-technical users.

Live: https://bristihalder.github.io/cheerio-setup-copilot/

It shows one scenario end to end. A Growth-plan user's WhatsApp template is rejected. An in-app copilot diagnoses it, rewrites the template, and resubmits it. The prototype also covers four edge cases and the support agent's view of a handoff. All names and numbers are sample data.
