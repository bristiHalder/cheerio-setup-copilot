What this prototype covers

  • One real scenario end to end: rejected template → diagnosis → fix → resubmit → outcome.
  • Four edge cases: repeat failure with escalation, user demands a human, Meta data unavailable, plan cap reached.
  • The support agent's side of a handoff.

Design rules shown

  • Copilot reads live account state and shows it as chips before saying anything.
  • Every fix needs a confirm click; actions are listed and undoable.
  • Money is shown whenever a fix changes the Meta message rate.
  • “Did this solve it?” is asked once; it feeds the North Star.

Not in scope

  • Meta business verification and bans (human only).
  • Billing disputes and refunds.
  • Custom integration development.
  • Chatbot flow and webhook screens (month 3 of rollout).
